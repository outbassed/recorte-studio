## Assets

Todos os personagens, cenários, objetos, expressões e cabelos do Recorte Studio são gerados por código escrito para este projeto, sem imagens de terceiros. A estética de recorte é uma linguagem visual genérica; nenhum personagem, logotipo ou arte de outra obra foi reproduzido.

O nome "Bar do Zé" e a "Cantina" nos cenários são fictícios.

## Observações

- Textos em balões usam fontes do sistema (Trebuchet MS, com alternativas). Elas não são distribuídas, por isso o desenho do texto pode variar entre sistemas operacionais.
- Codecs de vídeo e áudio são os do navegador. O uso de H.264 e AAC segue a licença do navegador.
